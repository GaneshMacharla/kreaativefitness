## 🚀 How to Run & Deploy

### Option 1: Direct File Open
Simply double-click `index.html` in Windows Explorer to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Local HTTP Preview Server
Run:
```bash
python -m http.server 8080
```
Then visit: [http://localhost:8080](http://localhost:8080)

### Option 3: Free Cloud Hosting
Because it is a 100% static site with zero dynamic backend dependencies, it can be hosted in seconds for free on:
- **Netlify:** Drag and drop this folder onto netlify.com/drop
- **Vercel:** Run `vercel deploy` or connect your Git repository
- **GitHub Pages:** Push to a GitHub repository and turn on Pages in repository settings
